**Ce que je sais faire (aujourd'hui)**
- Qualifier un IOC : hash, IP, URL, domaine (VirusTotal, AbuseIPDB, URLhaus)
- Écrire une règle de détection simple au format **Sigma** et la mapper à MITRE ATT&CK
- Lire un PCAP et identifier des protocoles (DNS, HTTP, TCP) avec **Wireshark**
- Trier une alerte et rédiger une fiche d'incident (contexte → analyse → remédiation)

**Ce que j'apprends (en cours) 🚧**
- Déploiement d'un mini-SIEM **Wazuh** (agents Linux/Windows, simulation d'attaques)
- Automatisation de tâches avec **SOAR** (Shuffle / n8n)
- Threat Intelligence avec **MISP** et exploitation d'IOC dans les logs
